# EliteDevelop

EliteDevelop is a free web-based developer and community platform built with Django.

> Website: [EliteDevelop](https://elitedevelop.pythonanywhere.com)

## Features

1. Community Messaging — Community chats, private messaging, and DMs
2. QR Code Generator — Generate QR codes directly from the web
3. Python Executor — Run Python code through the browser
4. EliteOS — A web-based operating system currently in development
5. Forms — Create and manage web-based forms
6. Proxy — A web proxy powered by Cloudflare Workers
7. Forums — Community discussion forums
8. Sign in with Google — Sign in securely using your Google account

## Project Status

EliteDevelop is actively being developed. Features, design, and functionality may change as development continues.
